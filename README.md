# Lymphoma Risk Assessment (LyRA): A cfDNA analysis pipeline for the development of a liquid biopsy test to detect canine lymphoma risk

This repository contains all code to process and analyze cfDNA samples for the LyRA1 cohort of the LyRA project.


## Data Overview

LyRA1 represents the initial LyRA training set, totaling 521 samples from 218 dogs across 5 disease cohorts:

          
| Cohort                  | Description                                          | # of Samples |
| -------------------     | ---------------------------------------------------- | -------------|
| Healthy                 | Control cohort                                       | 37           |
| DLBCL                   | DLBCL samples                                        | 83           |
| Other lymphoma          | MZL, T-cell lymphomas etc.                           | 41           |
| Non-lymphoid malignancy | Mast cell tumor, osteosarcoma, hemangiosarcoma, etc. | 26           |
| Chronic disease         | Mix of skin-related and non-skin diseases            | 32           |


Samples contain a mix of EDTA plasma (*n=203*), serum (*n=217*), and streck (*n=101*).

## Project Structure

| Directory      | Description                                                                              |
| -------------- | ---------------------------------------------------------------------------------------- |
| `README.md`    | Project overview and general directions                                                  |
| `code/`        | All analysis scripts and code                                                            |
| `inputs/`      | Input files (or symlinks to input data) that get sourced by pipeline code                |
| `meta/`        | Relevant metadata, including sample metadata and details                                 |
| `out/`         | Pipeline output generated by scripts in `code/` (not tracked)                            |
| `out_demo/`    | Example contents of an output folder generated by the pipeline                           |
